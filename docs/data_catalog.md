Data Catalog

The Gold layer represents the business-ready data model used for reporting and analytics. It follows a star schema composed of customer and product dimensions connected to a central sales fact table.
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
gold.dim_customers
Stores descriptive information about each customer. Each row represents one unique customer.
----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
| Column Name       | Data Type      | Description                                                                                    |
| ----------------- | -------------- | ---------------------------------------------------------------------------------------------- |
| `customer_key`    | `BIGINT`       | Surrogate key generated by the data warehouse to uniquely identify each customer. Primary key. |
| `customer_id`     | `INT`          | Original customer identifier from the CRM source system.                                       |
| `customer_number` | `NVARCHAR(50)` | Business identifier assigned to the customer in the source system.                             |
| `first_name`      | `NVARCHAR(50)` | Customer's first name.                                                                         |
| `last_name`       | `NVARCHAR(50)` | Customer's last name.                                                                          |
| `country`         | `NVARCHAR(50)` | Customer's country of residence, standardized from the ERP location data.                      |
| `marital_status`  | `NVARCHAR(50)` | Customer's marital status.                                                                     |
| `gender`          | `NVARCHAR(50)` | Customer's gender. CRM is used as the primary source and ERP as a fallback.                    |
| `birthdate`       | `DATE`         | Customer's date of birth.                                                                      |
| `create_date`     | `DATE`         | Date when the customer record was created in the source system.                                |

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
gold.dim_products
Stores descriptive information about products. Only the current version of each product is included.
| Column Name      | Data Type      | Description                                                                                   |
| ---------------- | -------------- | --------------------------------------------------------------------------------------------- |
| `product_key`    | `BIGINT`       | Surrogate key generated by the data warehouse to uniquely identify each product. Primary key. |
| `product_id`     | `INT`          | Original product identifier from the CRM source system.                                       |
| `product_number` | `NVARCHAR(50)` | Business product code used to connect products with sales transactions.                       |
| `product_name`   | `NVARCHAR(50)` | Descriptive name of the product.                                                              |
| `category_id`    | `NVARCHAR(50)` | Identifier of the product category.                                                           |
| `category`       | `NVARCHAR(50)` | Main category assigned to the product.                                                        |
| `subcategory`    | `NVARCHAR(50)` | More specific classification within the product category.                                     |
| `maintenance`    | `NVARCHAR(50)` | Indicates whether the product requires maintenance.                                           |
| `cost`           | `INT`          | Cost associated with producing or acquiring the product.                                      |
| `product_line`   | `NVARCHAR(50)` | Product line classification, such as Mountain, Road, Touring, or Other Sales.                 |
| `start_date`     | `DATE`         | Date when the current product record became active.                                           |

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
gold.fact_sales
Stores measurable sales transactions. Each row represents an individual product included in a sales order.
| Column Name     | Data Type      | Description                                                                        |
| --------------- | -------------- | ---------------------------------------------------------------------------------- |
| `order_number`  | `NVARCHAR(50)` | Business identifier of the sales order.                                            |
| `product_key`   | `BIGINT`       | Foreign key referencing `gold.dim_products.product_key`.                           |
| `customer_key`  | `BIGINT`       | Foreign key referencing `gold.dim_customers.customer_key`.                         |
| `order_date`    | `DATE`         | Date when the customer placed the order.                                           |
| `shipping_date` | `DATE`         | Date when the order was shipped.                                                   |
| `due_date`      | `DATE`         | Expected delivery or completion date of the order.                                 |
| `sales_amount`  | `INT`          | Total sales value for the transaction, calculated as quantity multiplied by price. |
| `quantity`      | `INT`          | Number of product units sold in the transaction.                                   |
| `price`         | `INT`          | Selling price per product unit.                                                    |

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Data Model Relationships
| Source Table         | Source Column  | Related Table     | Related Column | Relationship |
| -------------------- | -------------- | ----------------- | -------------- | ------------ |
| `gold.dim_customers` | `customer_key` | `gold.fact_sales` | `customer_key` | One-to-many  |
| `gold.dim_products`  | `product_key`  | `gold.fact_sales` | `product_key`  | One-to-many  |

-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------
Business Calculation

The sales amount is calculated using:
Sales Amount = Quantity × Price
The fact table contains transaction measurements, while the dimension tables provide the customer and product information required to analyze sales by country, category, product line, gender, date, and other business attributes.
